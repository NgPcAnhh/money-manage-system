Hướng Dẫn Triển Khai GitHub Pages

1
Tạo Repository mới trên GitHub

Đặt tên repo ví dụ: my-finance hoặc mms (chế độ Public).

2
Đẩy toàn bộ mã nguồn lên repo

Commit và Push các file: index.html, css/, js/, README.md.

3
Bật GitHub Pages

Vào Settings → Pages → Source chọn Deploy from a branch → Chọn Branch main và folder / (root) → Save.

4
Truy cập từ iPhone 15 Pro Max

Mở link: https://<username>.github.io/<repo>/ trên Safari → Bấm "Chia sẻ" → Chọn "Thêm vào Màn hình chính" (Add to Home Screen) để dùng như app thực thụ!
